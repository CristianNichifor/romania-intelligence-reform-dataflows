# Errata

Corrections to the data, sources and documents of this demo. The flows simplify
public law and published research; if something is wrong, outdated or unsourced,
please say so.

## Report a correction

Open an issue at
<https://github.com/CristianNichifor/romania-intelligence-reform-dataflows/issues>
with the flow ID (for example `C6`) or the document, what is wrong, and a public
source for the correct version. Accepted corrections are logged below.
