Fluxul T3–T6: handshake de date interinstituțional

Un analist SRI cere date deținute de SIE. Conținutul circulă doar cu un token de mandat SSC; brokerul IADE vede doar metadate; fiecare pas ajunge în registrul de audit.

PAS 06/11
  1. Analist SRI
    Creează obiectul de cerere · finalizat
    ID caz, temei legal, subiecți minimizați, câmpuri solicitate, justificare.
  2. SRI → SSC
    Solicită token de mandat interinstituțional · finalizat
  3. SSC
    Validează temeiul + specificitatea · finalizat
    Verificare dublă: temei în sfera legală, nu e expediție de pescuit, nu există mijloace mai puțin intruzive.
  4. SSC
    Emite token criptografic de mandat · finalizat · W1
  5. SRI → IADE
    Trimite Cerere + Token · finalizat · T3
  6. IADE
    Validează semnătura tokenului, înregistrează, rutează · în curs · T4
    Tranzacția e înregistrată (ID cerere, timestamp, agenții, ID token, temei — nu conținut).
  7. SIE
    Validează tokenul, preia datele, minimizează
  8. SIE → IADE
    Returnează pachetul de răspuns · T5
  9. IADE
    Înregistrează metadatele răspunsului, rutează către SRI · T6
  10. SRI
    Atașează la dosarul de caz
  11. IG
    Interoghează registrul de audit după ID caz
